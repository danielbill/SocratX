### 阶段 4: 高级样式效果 (优先级: P2)

#### 4.1 Shimmer Hover 效果
```css
/* 扫光悬停效果 */
@keyframes shimmer {
  0% { background-position: -200% 0; }
  100% { background-position: 200% 0; }
}

.shimmer-hover:hover {
  background: linear-gradient(
    90deg,
    transparent 0%,
    rgba(255,255,255,0.1) 50%,
    transparent 100%
  );
  background-size: 200% 100%;
  animation: shimmer 1.5s infinite;
}
```

#### 4.2 Trailing Border 效果
```css
/* 旋转渐变边框 */
.trailing-border::before {
  content: '';
  position: absolute;
  inset: -2px;
  background: conic-gradient(
    from 0deg,
    transparent 0deg,
    var(--primary) 90deg,
    transparent 90deg
  );
  animation: rotate 4s linear infinite;
}
```

**预计时间**: 2 小时

## 三、样式规范

### 颜色系统 (升级到 OKLCH)
```css
@theme {
  /* 主色 */
  --color-primary: oklch(0.7 0.15 250);
  --color-secondary: oklch(0.65 0.12 200);

  /* 中性色 */
  --color-bg: oklch(0.15 0.01 250);
  --color-surface: oklch(0.2 0.01 250);
  --color-border: oklch(0.25 0.01 250);

  /* 语义色 */
  --color-success: oklch(0.7 0.15 145);
  --color-warning: oklch(0.75 0.12 85);
  --color-error: oklch(0.65 0.2 25);
  --color-info: oklch(0.65 0.15 250);
}

@theme dark {
  --color-bg: oklch(0.15 0.01 250);
  --color-surface: oklch(0.2 0.01 250);
  /* ... */
}
```

### 排版系统
```css
/* 字体大小 */
--text-xs: 0.75rem;    /* 12px */
--text-sm: 0.875rem;   /* 14px */
--text-base: 1rem;     /* 16px */
--text-lg: 1.125rem;   /* 18px */
--text-xl: 1.25rem;    /* 20px */
--text-2xl: 1.5rem;    /* 24px */

/* 字重 */
--font-normal: 400;
--font-medium: 500;
--font-semibold: 600;
--font-bold: 700;
```

### 间距系统
```css
/* 使用 Tailwind 默认间距 */
--spacing-1: 0.25rem;  /* 4px */
--spacing-2: 0.5rem;   /* 8px */
--spacing-3: 0.75rem;  /* 12px */
--spacing-4: 1rem;     /* 16px */
--spacing-6: 1.5rem;   /* 24px */
--spacing-8: 2rem;     /* 32px */
```
