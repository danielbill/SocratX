## 工作规则

1. **进度检查**: 不确定进度时，先检查 `dev_backend_todos.md`
2. **及时更新**: 完成任务后，立即更新 `dev_backend_todos.md`
3. **单一目标**: 一次只完成一个目标，完成后汇报，等用户确认
4. **详细计划**: 任务复杂度超过 3 分钟时，创建详细 todo list 并更新到日志
5. **步骤更新**: 每完成一个步骤，更新 todo list
6.**工作流程** ：
    1、了解需求，澄清需求，哪怕有1%不清楚的地方也要询问用户彻底搞清楚
    2、进行设计，根据用户提供的 "RP" 开头的任务信息，在后端 设计文档 目录下创建编号统一的设计文档；将需求拆分为更细粒度的实现模块，逐个模块进行设计。
    3、设计完成后，向用户展示，如有疑问向用户提出。
    4、循环1-3步骤，直到用户确认所有设计，确认可以执行，再进入编码环节。
    5、编码前更新todolist，管理用户需求编号及设计文档！

## 核心职责

### 1. Agent 核心开发
- `agent/loop.py` - Agent 主循环
- `agent/context.py` - 上下文管理
- `agent/session.py` - 会话管理
- `agent/memory.py` - 记忆存储

### 2. Provider 集成
- `providers/registry.py` - LLM 提供商注册表
- `providers/litellm_provider.py` - LiteLLM 集成
- 支持 15+ LLM 提供商 (OpenAI, Anthropic, Gemini 等)

### 3. 工具系统
- `tools/registry.py` - 工具注册表
- `tools/base.py` - 工具基类
- 内置工具：文件、Shell、网络、计算器

### 4. API 服务
- FastAPI 侧边车模式
- RESTful API 端点
- WebSocket 实时通信

### 5. 配置系统
- `config/` - 配置管理
- 支持多环境配置
- 密钥安全管理

## 开发原则

1. **类型安全**: 完整 TypeScript 类型注解
2. **异步优先**: 使用 asyncio 处理 IO 密集型任务
3. **错误处理**: 明确的异常处理和用户友好错误
4. **日志记录**: 结构化日志，便于调试
