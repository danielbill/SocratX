# SocratX 测试指南

本文档介绍如何运行和维护 SocratX 项目的测试。

---

## 测试框架

| 模块 | 测试框架 | 配置 |
|------|---------|------|
| **前端 (React)** | Vitest + React Testing Library | `apps/desktop/vite.config.ts` |
| **Python 后端** | pytest + pytest-asyncio | `services/agent/pytest.ini` |
| **Rust (Tauri)** | Rust 内置测试 | `apps/desktop/src-tauri/Cargo.toml` |

### 编写测试

测试文件命名：`*.test.ts` 或 `*.test.tsx`

**示例：组件测试**

```typescript
import { render, screen } from '@testing-library/react'
import userEvent from '@testing-library/user-event'
import { describe, it, expect, vi } from 'vitest'
import ChatInput from './ChatInput'

describe('ChatInput', () => {
  it('渲染输入框', () => {
    render(<ChatInput onSend={() => {}} disabled={false} />)
    expect(screen.getByPlaceholderText(/输入/i)).toBeInTheDocument()
  })

  it('点击发送触发回调', async () => {
    const onSend = vi.fn()
    const user = userEvent.setup()
    
    render(<ChatInput onSend={onSend} disabled={false} />)
    
    await user.type(screen.getByPlaceholderText(/输入/i), 'Hello')
    await user.click(screen.getByRole('button'))
    
    expect(onSend).toHaveBeenCalledWith('Hello')
  })
})
```

### 测试工具函数

```typescript
import { describe, it, expect } from 'vitest'
import { cn } from './utils'

describe('utils', () => {
  describe('cn', () => {
    it('合并多个类名', () => {
      expect(cn('a', 'b', 'c')).toBe('a b c')
    })
  })
})
```

## Python 测试（pytest）

### 运行测试

```bash
cd services/agent

# 运行所有测试

# 详细输出
pytest -v

# 生成覆盖率报告
pytest --cov=agent --cov-report=html

# 监视模式
pytest -w

# 运行特定测试
pytest tests/test_agent/test_memory.py::TestMemoryStore::test_get_memory
```

### 编写测试

测试文件命名：`test_*.py`

**示例：单元测试**

```python
import pytest
from agent.memory import MemoryStore

class TestMemoryStore:
    @pytest.fixture
    def memory_store(self, tmp_path):
        return MemoryStore(tmp_path)

    def test_update_memory(self, memory_store):
        import asyncio
        asyncio.run(memory_store.update_memory("Test item"))
        
        content = asyncio.run(memory_store.get_memory())
        assert "Test item" in content
```

**示例：API 测试**

```python
import pytest
from fastapi.testclient import TestClient
from main import app

@pytest.fixture
def client():
    return TestClient(app)

def test_chat_endpoint(client):
    response = client.post(
        "/api/chat",
        json={"message": "Hello", "session_id": "test"}
    )
    assert response.status_code == 200
```

### 使用夹具（Fixtures）

```python
# tests/conftest.py
import pytest
from fastapi.testclient import TestClient
from main import app

@pytest.fixture
def client():
    return TestClient(app)

@pytest.fixture
def mock_llm_response(mocker):
    return mocker.patch(
        'litellm.completion',
        return_value={'choices': [{'message': {'content': 'Mock'}}]}
    )
```

## Rust 测试

### 运行测试

```bash
cd apps/desktop/src-tauri

# 运行所有测试
cargo test

# 运行特定测试
cargo test test_greet

# 显示输出
cargo test -- --nocapture
```

### 编写测试

```rust
#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn test_greet() {
        let result = greet("Alice");
        assert_eq!(result, "Hello, Alice! You've been greeted from Rust!");
    }

    #[test]
    fn test_greet_empty_name() {
        let result = greet("");
        assert_eq!(result, "Hello, ! You've been greeted from Rust!");
    }
}
```

## 测试最佳实践

### 1. 测试命名

```typescript
// ✅ 好的命名
it('渲染输入框', () => {})
it('点击发送按钮触发回调', () => {})
it('禁用状态下无法发送', () => {})

// ❌ 避免
it('test 1', () => {})
it('should work', () => {})
```

### 2. 测试独立性

```typescript
// ✅ 每个测试独立
it('测试 A', () => {
  const { container } = render(<Component />)
})

it('测试 B', () => {
  const { container } = render(<Component />) // 重新渲染
})
```

### 3. 测试边界条件

```typescript
// 测试空值、边界值、异常
it('处理空消息', () => {})
it('处理超长消息', () => {})
it('网络错误时显示友好提示', () => {})
```

### 4. 使用工厂函数

```typescript
// ✅ 使用工厂
const createMessage = (overrides = {}) => ({
  id: '1',
  role: 'user',
  content: 'Test',
  ...overrides,
})

it('使用工厂函数', () => {
```

## 常见问题

### Q: 测试运行太慢？

**解决方案**：
- 使用 `--changed` 只运行变更测试
- 配置测试缓存
- 分离单元测试和集成测试

### Q: Mock 太多怎么办？

**解决方案**：
- 优先测试公共 API
- 使用集成测试补充
- Mock 外部依赖，不 Mock 内部逻辑

### Q: 如何处理异步测试？

**前端**：
```typescript
it('异步操作', async () => {
  await act(async () => {
    await someAsyncFunction()
  })
})
```

**Python**：
```python
@pytest.mark.asyncio
async def test_async():
    result = await async_function()
    assert result == "expected"
```
